# ATLAS UI Kit — Дизайн-система Help Desk

## Как запустить
1. Откройте терминал в папке проекта.
2. Запустите локальный сервер: `python -m http.server 5500`
3. Перейдите в браузере по адресу: `http://localhost:5500`

## Схема токенов (primitive → semantic → component)
В проекте реализована трёхуровневая архитектура дизайн-токенов. Вот 3 реальные цепочки:

1. **Цвет кнопки:**
   `--base-blue-700 (#1853a4)` → `--color-primary` → `--button-bg-primary` → `.button--primary { background }`
2. **Цвет текста:**
   `--base-slate-950 (#142338)` → `--color-text` → `body { color }`
3. **Высота интерактивных элементов:**
   `2.75rem` → `--button-height` → `.button { min-height }`

## Таблица проверок «условие — результат»

| Условие | Результат |
| :--- | :--- |
| 320, 375, 768, 1024, 1440 px | Контент не обрезан, горизонтального скролла нет |
| Tab и Shift+Tab | Фокус виден на всех интерактивных элементах |
| Auto / light / dark | Корректная тема, ручной выбор имеет приоритет над системным |
| Обновление страницы | Выбор темы и плотности сохраняется в localStorage |
| :hover, :active, :disabled | Кнопки визуально отличаются по состояниям |
| Ошибка поля | Есть красная граница и связанный текст (aria-describedby) |
| Изменение --color-primary | Заливка кнопок, логотип и образец цвета изменились без правки компонентов |

## Ответы на вопросы для защиты (по 2–3 предложения)

**а) Почему плотность задаётся компонентными токенами?**
Потому что плотность влияет на конкретные размеры компонентов (высоту кнопок, отступы полей), а не на глобальные цвета. Использование компонентных токенов (`--button-height`, `--control-height`) позволяет переключать режим одним атрибутом `data-density` на корне, не дублируя стили всех кнопок и полей.

**б) Почему тёмная тема не должна хранить прямые цвета внутри `.button`?**
Потому что при смене темы компонент должен автоматически перекрашиваться. Если внутри `.button` написать прямой HEX (например, `#1853a4`), то в тёмной теме кнопка останется светлой. Использование `var(--color-primary)` позволяет CSS-переменным подменить цвет на уровне `:root`, и кнопка меняется сама.
