# CampusFlow

Учебный проект — веб-сервис для поиска и регистрации на учебные мероприятия.

## Практическая работа №1

Проведён инженерный анализ макета, подготовлен технический фундамент проекта.

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Устанавливает зависимости |
| `npm run dev` | Запускает dev-сервер (http://localhost:5173/) |
| `npm run build` | Собирает проект в `dist/` |
| `npm run preview` | Просмотр production-сборки |
| `npm run lint` | Проверка JS через ESLint |
| `npm run lint:css` | Проверка CSS через Stylelint |
| `npm run format` | Форматирование через Prettier |

## Структура
campusflow/
├── index.html # Каталог (заготовка)
├── event.html # Страница мероприятия (HTML-каркас)
├── src/
│ ├── assets/ # Изображения, иконки
│ ├── data/ # Данные (JSON-заглушки)
│ ├── js/ # Скрипты
│ │ ├── components/ # Компоненты
│ │ └── pages/ # Логика страниц
│ ├── styles/ # Стили
│ │ └── base.css # Базовые стили и переменные
│ └── main.js # Точка входа
└── decomposition.md # Декомпозиция проекта
